# Ficha del proyecto

## Red de Semillas Andinas

Cusco, Perú

### Quiénes somos

Somos una red de familias campesinas que guarda variedades nativas de papa y quinua y las intercambia en ferias comunitarias.

### Lo que necesitamos

- Un almacén fresco para las semillas
- Capacitación en registro de variedades
- Fondos para tres ferias al año

### Lo que ofrecemos

- Semillas nativas para huertos escolares
- Talleres sobre cultivos andinos
